# Митрандир — презентация команды «ИИ бланки»

7 основных слайдов: 285 секунд содержания + 15 секунд резерва. Ещё 5 слайдов — для вопросов. Локальные HTML/CSS/JS, SVG и шрифты; backend и интернет для показа не нужны.

## Запуск

Откройте `presentation/index.html` напрямую. После обновления — Ctrl+Shift+R, затем Home.

Необязательный сервер из корня репозитория:

```bash
python3 -m http.server 8088 --bind 127.0.0.1 --directory presentation
```

Адрес: `http://127.0.0.1:8088/`. Переносить нужно всю папку `presentation/`.

## Управление

- → / ← — следующий / предыдущий слайд или этап.
- S2: запрос → компания → основание. S4: пять акцентов пути запроса. S5: три фактора.
- На S7 нажмите ↓ для запасных. В запасных ← / → листают, ↑ возвращает к выступлению.
- Home / End — первый / последний основной. F / F11 — полный экран. Пробел и PageDown/PageUp также работают.

Запасные не открываются автоматически. Кнопок и режима заметок нет. Слайд и этап восстанавливаются после обновления. Ток на архитектуре идёт постоянно; при системном reduced motion и в фоне движение останавливается. Анимация условная, она не измеряет скорость backend.

## Источники и границы

Основа актуализации — origin/main `1394a5d`, включая новый default D-171 (R-long). На S1 по прямому указанию пользователя оставлены только кейс, решение и команда; ТСК и статистика со вступления убраны. Стиль главной сохранён: Tektur, тёмное стекло, локальные MTS Text для основного текста (`assets/MTS-SOURCE.txt`).

S2 — редактируемый разбор сохранённого ответа `assets/example.json`, не снимок UI. S5 сохраняет факты 126 похожих лотов и 36 побед. Конкретное место и сравнение с соседом из старой E12a удалены после смены модели. S3 использует **отдельный** запрос про шкафы `assets/example-new.json`: 10 новых компаний, две показаны как примеры разных оснований. Ни один старый PNG интерфейса в показе не используется.

S6: готовые отчёты `L-long.json` / `B-bm25.json`, одинаковые 2 000 dev-query_id. B2 дополнительно показывает проверку `LF-long` / `LF-base` на другой выборке из dev_full. Выбор модели выполнен на dev; независимый holdout не измерен. Вход содержит текст, ОКПД2 и контекст закупки. Значения, версии и условия — в `evidence.md`.

Локальная проверка запроса после обновления Git обнаружила старый `data/processed` **без профилей поставщиков**. В старом корневом `.venv` также отсутствует LightGBM. В изолированном окружении модель загрузилась, но из-за пустых профильных признаков порядок отличается от сохранённого E12a. Это не новый замер качества. Для живого продуктового демо нужна актуальная подготовленная выгрузка и окружение; в этой задаче данные не пересобирались и не переиндексировались. Автономная презентация от них не зависит.

## Файлы

- `index.html` — редактируемые слайды и скрытый текст докладчика.
- `ui-design.css`, `styles.css` — композиция и оформление.
- `app.js` — клавиатура и восстановление; `motion.js` / `motion.css` — анимации.
- `assets/tech/` — SVG технологий. `assets/example*.json` — сохранённые примеры.
- `storyboard.md` — полный текст, переходы и тайминг; `evidence.md` — реестр доказательств и ограничений.
- `defense-structure.md` — исходная структура; последние изменения пользователя отражены в storyboard.

## Проверки

Chromium запущен офлайн: 7 основных и 5 запасных слайдов, все три состояния S2. Проверены границы текста, стрелки, возврат из запаса, refresh, fullscreen, отсутствие экранных кнопок и старых PNG-карточек. Внешних запросов и ошибок JavaScript нет. Итог: 50 браузерных, 19 содержательных и 17 анимационных проверок прошли. `make check-changed`: 1919 passed, 36 skipped после синхронизации с main 6525a0e (02.10.2026).

```bash

node presentation/checks/verify.mjs

Playwright берётся из `src/ui/node_modules`. Новые eval, обучение и переиндексация не запускаются. Репетиция, физический проектор, Safari/Firefox не проверены.
