# Митрандир — защита через пайплайн

8 основных слайдов, **300 секунд**; 5 запасных. Архив предыдущей версии: `/home/m1x/Documents/hackathons/rlt-local-backups/presentation-before-team-pipeline.zip`.

## Запуск

Откройте `presentation/index.html` локально. Backend, интернет и установка зависимостей для показа не нужны. После замены файлов — Ctrl+Shift+R, затем Home.

Необязательный сервер из корня репозитория:

```bash
python3 -m http.server 8088 --bind 127.0.0.1 --directory presentation
```

## Управление

- ← / →, пробел — слайды и этапы; S2/S3/S5 по 3 этапа, S4 — 5.
- Home / End — первый слайд / команда. F или F11 — полный экран.
- На команде ↓ открывает запасные, ← / → листают их, ↑ возвращает.
- Слайд и этап сохраняются после обновления. Запасные не открываются автоматически.
- Кнопок, режима заметок и переключателя анимаций нет. Скрытые заметки доступны в HTML и `speech.md`.
- Ток на схеме запроса движется непрерывно. Системное `prefers-reduced-motion` останавливает движение, весь контент остаётся видимым.

- `ui-design.css`, `styles.css` — оформление; `motion.js` / `motion.css` — анимации, `app.js` — навигация.
- `assets/team/member-1.png` … `member-5.png` — предоставленные фотографии. Кадрирование только CSS `.portrait-N`; оригиналы не изменены. Имена в S8; роли не предоставлены.
- `assets/tech/` — локальные значки стека.
- `speech.md` — простой текст выступления; `storyboard.md` — тезисы, вопросы, визуалы, переходы.
- `evidence.md` — актуальные факты и ограничения; `evidence-history.md` — архив прежних редакций.

81% — округление 80,508% winner@10 на 590 закупках ЭМ со знакомым заказчику победителем, выбранный сильный срез. График отдельно: Recall@10 на 889 закупках с новым победителем, L-long / B-inc ≈ 3,0. Это две разные метрики на разных срезах; не общий результат для всех закупок. Методика и версии — B2 и evidence.md. Векторная ветка реализована, но YAML выбирает BM25.
