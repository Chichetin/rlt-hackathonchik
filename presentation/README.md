## Запуск и управление

Открыть `presentation/index.html`. После обновления — Ctrl+Shift+R, Home. Backend и интернет не нужны, все шрифты и assets локальные.

Необязательный сервер из корня репозитория:

```bash
python3 -m http.server 8088 --bind 127.0.0.1 --directory presentation
```

- ← / →, пробел — переходы; на S2/S3/S5 выделяют 3 стадии, на S4 — 5 компонентов.
- Home / End — начало / финал. F или F11 — полный экран.
- На финале ↓ — запасные; там ← / → листают, ↑ возвращает.
- Слайд и шаг восстанавливаются после refresh. Кнопок, режима заметок и переключателя анимаций нет.
- Ток на архитектуре движется постоянно. График прорисовывается при входе. Системный reduced motion отключает движение и сохраняет весь смысл.

## Основной маршрут

| № | Вопрос | План |
|---|---|---:|
| 1 | Кейс, Митрандир, ИИ бланки | 20 с |
| 2 | Полный путь: CSV → индексы → подбор → фильтры → сайт | 60 с |

| | Всего | 300 с |

Это план для репетиции. Основной рассказ больше не является переключением карточки поставщика. На S2 показан полный путь: исходные файлы жюри, очистка, хранилище, текстовый индекс и опциональная векторизация, запрос с сайта, кандидаты, оценка, обогащение, фильтры и выдача. Критерии указаны рядом с этапами.

LightGBM применяется при известном заказчике; без него — формула с отдельными потолками опыта 100/50. С заказчиком сохранены 20/10. Непроверенный статус сам по себе не исключает, но включённый фильтр «только МСП» требует подтверждения. Сегодняшние статусы не используются в историческом backtest.

## Редактирование и доказательства

- `index.html` — весь контент, SVG и скрытый текст выступления.
- `ui-design.css` / `styles.css` — оформление. `app.js` — стрелки, fullscreen, refresh. `motion.js` / `motion.css` — анимации.
- `speech.md` — простой текст выступления без технических сокращений.
- `storyboard.md` — вопросы, тезисы, визуальные объекты, полный текст и переходы.
- `evidence.md` — актуальный реестр с кодом, версиями метрик и ограничениями. `evidence-history.md` — предыдущие редакции, не источник текущего статуса.
- `assets/tech/` — локальные SVG технологий; `assets/example*.json` — исторические примеры для резерва.
- `checks/` — скрипты, результаты браузерных проверок, кадры и видео.

## Проверки

```bash
node --check presentation/app.js
node --check presentation/motion.js
node presentation/checks/verify.mjs
node presentation/checks/content-check.mjs
node presentation/checks/motion-check.mjs
make check-changed
```

Playwright берётся из `src/ui/node_modules`. В worktree можно задать `PLAYWRIGHT_MODULE=/полный/путь/к/playwright-core/index.mjs`. Источники eval/code для content-check — корень текущего worktree; подготовленный dataset не требуется.

Chromium открывает все 7 основных и 5 запасных, проверяет этапы стрелками, границы текста, refresh, fullscreen, возврат и отсутствие внешних запросов. Размеры: 1600×900, 1280×720, 1024×768, 2048×1180. Точные результаты — в checks/*-report.json.

Не проверены: выступление с секундомером, проектор, Safari/Firefox, новый end-to-end продукта. Локальные подготовленные данные ранее оказались без профилей поставщиков, старое root-окружение без LightGBM. Презентация от них не зависит. Не запускались обучение, eval, ingest и переиндексация. Авторские изменения только в presentation/.
