# Митрандир — презентация защиты

7 основных слайдов / 285 секунд содержания + 15 секунд резерва, 5 запасных. HTML/CSS/JS, локальные шрифты и SVG. Открывается без backend и интернета.

## Открыть

Двойной щелчок по `presentation/index.html`. После обновления файлов — Ctrl+Shift+R. Для показа сначала нажмите Home.

При желании, из корня репозитория:

```bash
python3 -m http.server 8088 --bind 127.0.0.1 --directory presentation
```

Адрес: `http://127.0.0.1:8088/`. Для переноса нужна вся папка `presentation/`.

## Управление без мыши

- **→ / ←** — следующий / предыдущий слайд или этап рассказа.
- На **S2**: запрос → компания → основание → следующий слайд. Обратный ход сохраняет логический порядок.
- На **S4** — пять акцентов запроса; на **S5** — три фактора. Ток на S4 идёт постоянно и не зависит от нажатий.
- На финальном **S7 нажмите ↓**, чтобы явно открыть запасные слайды. **← / →** листают их; **↑** возвращает к выступлению. Запасные не открываются автоматически по → после финала.
- **Home / End** — первый / последний основной слайд. **F / F11** — полный экран. Пробел и PageDown/PageUp тоже работают.

Кнопок, диалогов, режима заметок и переключателя анимаций нет. Текст доклада лежит в `storyboard.md`. Последний слайд и этап восстанавливаются после refresh.

Системная настройка `prefers-reduced-motion` сохраняется: движение останавливается, содержание остаётся. При уходе вкладки в фон движение приостанавливается. Это не отдельный режим презентации.

## Дизайн и содержание примера

Сверены обновлённые `work-typography.css` и `work-glass.css`, реально открыт текущий `/search` в Chromium. Рабочий интерфейс использует MTS Text и нейтральное тёмное стекло; крупные заголовки презентации сохраняют Tektur главной. Шрифты скопированы локально без изменений. Происхождение MTS Text: `assets/MTS-SOURCE.txt`.

Растровые карточки **не используются в показе**. S1 и S2 — редактируемая HTML-композиция на полях сохранённого ответа `assets/example.json`, а не новый экран продукта. Данные компании, числа и свидетельство сохранены; полная форма ООО, общая история и лишние детали не отвлекают от конкретного запроса. Исходные снимки остаются только как локальные доказательства захвата UI.

Источники, версии, измерения и ограничения находятся в `evidence.md`, а служебные строки из подвалов слайдов убраны. Формула, точный score и лимиты кандидатов вынесены в B1/B3. На S5 — свидетельство и три причины.

На архитектуре по проводникам постоянно движутся световое ядро, хвост и декоративное «01». Это визуальное обозначение потока, не телеметрия и не измерение скорости backend. Петли существуют только на открытом S4 и удаляются при уходе. Остальные переходы конечные; автоперелистывания нет.

## Редактирование

- `index.html`: слайды, цифры, схема, скрытый текст докладчика. Скрытый текст не имеет режима показа аудитории.
- `ui-design.css`: текущая сетка, типографика и поверхности; `styles.css`: базовые стили.
- `motion.js` / `motion.css`: переходы, проводники и световые импульсы.
- `app.js`: клавиатурная навигация, этапы, восстановление и fullscreen.
- `assets/tech/`: редактируемые SVG-пиктограммы 12 технологий.
- `storyboard.md`: полный рассказ с переходами и таймингом; `evidence.md`: реестр доказательств.
