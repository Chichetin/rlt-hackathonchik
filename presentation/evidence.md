## Граница воспроизведения экранов

Снимки снимаются настоящим UI локального приложения в чистом Chromium с неизменёнными DOM/CSS. На `/api/search` браузер получает сохранённый настоящий ответ TestClient, без ручного сочинения результатов; фоновая карточка сохраняет тот же снимок поставщика. Это воспроизводимое состояние интерфейса с офлайн-ответом, не запись живого сетевого поиска. Служебные заголовки и полный JSON остаются в `/tmp`; в презентации — только минимальный пример, имя юрлица/ИНН, компоненты и историческое свидетельство. Персональные контакты и дампы корпуса не включаются.
