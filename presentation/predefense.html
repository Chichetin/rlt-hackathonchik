Оператор пишет описание закупки обычным текстом — через интерфейс или по API. Опечатки и английскую раскладку — в общем любые косяки оператора — мы исправляем сами. Нет кода ОКПД2 — определяем его по тексту по истории закупок: класс угадываем в 82 % случаев, а если товар уже встречался — в 92 %.

59 %реальных участников закупки в первой десятке — против 45 % у поиска по тексту и 39 % у истории заказчика
×3больше поставщиков, новых для заказчика
Оцениваем по шести критериям: соответствие товару, опыт в похожих закупках, надёжность, активность, цена и регион. Если заказчик известен — порядок задаёт обученная модель LightGBM: 44 признака, обучена на 12 тысячах прошлых закупок в четырёх квартальных окнах, строго по прошлому, без подглядывания в будущее. Если есть только описание — работает формула, настроенная отдельно под этот случай. Результат на двух тысячах закупок, которых модель не видела: в первой десятке 59 % реальных участников против 45 % у поиска по тексту и 39 % у истории заказчика; новых для заказчика поставщиков — в три раза больше.

Дальше — проверка по внешним источникам. Их у нас 13, плюс данные организаторов: ФНС — реестр малого бизнеса на 6,7 миллиона компаний, «Прозрачный бизнес», бухотчётность ГИР БО, открытые данные налоговой; ЕИС — реестр недобросовестных поставщиков и госконтракты; Минпромторг — госреестр ГИСП, 480 тысяч позиций и 8 тысяч производителей; реестр СРО НОСТРОЙ, сайты компаний через поиск Яндекса, отзывы 2ГИС; для поставщиков ЕАЭС — реестры Беларуси и Армении. «Прозрачный бизнес» закрыт капчей — мы написали своё распознавание; а если источник не отвечает, статус берём из ГИР БО и реестра МСП: у первой десятки он теперь проверен у 87 из 120 компаний против 20 раньше. Ликвидированных, банкротов и недобросовестных убираем автоматически. Отдельно ищем новых поставщиков, которых нет в истории: по реестру малого бизнеса и госреестру производителей — с госреестром доля подтверждённых выросла вдвое, с 11 до 21 на сотню. Если сильных кандидатов меньше трёх, дополнительных ищем через Yandex Search API — по товару, с проверкой ИНН на сайте. Итог: заказчик получает список за полсекунды, у каждой компании — почему она здесь и откуда каждый факт. Без языковых моделей, с API и выгрузкой в Excel — готово к встраиванию в АИС ГЗ.
