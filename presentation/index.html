К выдаче: кеш реестров + отдельный блок «Новые»Без LLM · векторная ветка выключена
Верхний контур работает при подготовке данных. Из CSV организаторов DuckDB собирает нормализованные извещения, позиции и участия. Поставщики объединяются по ИНН. В локальном варианте данные хранятся в Parquet; BM25 индексирует уникальные названия позиций и предметы лотов с участниками. Нижний контур обслуживает запрос. React передаёт его FastAPI. Поиск берёт до пятисот текстовых документов, связывает их с лотами, а лоты — с участниками. До двухсот кандидатов получают итоговую оценку и объяснения. Только после ранжирования конвейер добавляет факты из кеша, объединяет отдельный блок найденных через реестры компаний, применяет юридические и пользовательские фильтры. API делит результат на страницы и проверяет показываемые факты. Фоновый воркер может обновлять обогащение. Сейчас включены BM25 и H-15f; векторная ветка реализована отдельно, но выключена. Генеративная модель этому пути не нужна.

ОКВЭД — основание кандидата, не подтверждение нужного товара

Локальная проверка Parquet · ingest 01.10.2026 · сопоставление ОКПД2 / ОКВЭД эвристическое

Основной подбор опирается на связь компании с лотами. Если этой истории нет, реализована отдельная ветка: код категории сопоставляется с ОКВЭД, в реестре МСП ищутся компании, их ИНН проверяются на отсутствие в истории и факты проходят Evidence. Сопоставление категорий с оптовой торговлей задано вручную. Поэтому основание новой рекомендации слабее прямого свидетельства по позиции; роль по ОКВЭД не доказывает производство конкретного товара. В выбранном офлайн-запросе новых компаний нет. Данные организаторов тоже неполны: у части участий отсутствует КПП, а у части извещений — ИНН заказчика.

Равные оценки лидеров возможны: опыт насыщается.
Другие потолки насыщения — эксперимент; default остаётся 20 лотов / 10 побед.

Сервис объясняет, почему компания релевантна доступной истории. Он не гарантирует качество будущей поставки, актуальность каждого внешнего факта или экономию времени. По ходовым категориям опыт насыщается и оценки совпадают; настройка других потолков существует как эксперимент, в default не перенесена. Следующие проверки — независимый holdout, экспертная оценка рекомендаций и уточнение временных полей. Интеграционный пилот предлагается через готовый API; согласование с внешней системой пока впереди.
