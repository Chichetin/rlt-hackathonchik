## День 1, четверг 1 октября

| Время | Что | Критерий выхода |
|---|---|---|
| 10:00–10:15 | Постановка задачи | записаны данные, критерии, ответы на вопросы из `CLAUDE.md`, «Факты» |
| 10:15–10:40 | Kickoff (промпт 2) | «Факты» заполнены, роли подтверждены, `docs/kickoff-todo.md` пройден |
| 10:40–11:30 | Профилирование данных, проверка доступа к источникам, stub, каркас UI | `DATA_DICTIONARY.md` v0; контракты заморожены; известно, какие источники реально отвечают |
| 11:45–13:30 | Walking skeleton | запрос → кандидаты из данных организаторов → API → UI; обогащение по ИНН хотя бы из одного источника |
| 13:30–14:30 | Обед | агенты гоняют долгие задачи: индексы, эмбеддинги, пакетное обогащение |
| 14:30–15:30 | Backtest v0, discovery v0 | первая цифра качества против baseline; хотя бы одна новая компания из открытых источников в выдаче |
| 15:30–16:00 | Подготовка к чек-поинту | 4–5 слайдов и живой skeleton (`jury` перед показом) |
| 16:00–17:00 | **Чек-поинт 1** | фидбек записан в `research/DECISIONS.md` |
| 17:15–18:00 | Перепланирование, запуск ночных задач | ночные задачи возобновляемые, с логами и паузами между запросами |
| Вечер | Если правила разрешают — не больше 2–3 часов | второй день кончается в 21:00; защиту Топ-5 не ведёт невыспавшийся спикер |

**Жёсткое правило: если к 15:00 первого дня нет end-to-end на данных организаторов, все четверо
бросают текущие задачи и доводят skeleton.** Лучшая методология без работающего демо стоит ноль.
