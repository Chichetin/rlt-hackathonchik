автора. Правила — `CLAUDE.md`, контракты — `src/contracts.py`, пункты условий — таблица в

## Режим 1 — PR (по умолчанию)

Бриф: ветка, worktree, #N, PR, что заявил автор.

```bash
cd <worktree> && git fetch -q --prune
git diff --stat origin/main...HEAD && git diff origin/main...HEAD
git log --oneline origin/main..HEAD
gh issue view <N>                       # критерий приёмки
```

`Bash` — только чтение и быстрые проверки (`uv run --frozen pytest <файл>`, `make lint`,
`bash .claude/hooks/check-secrets.sh`, `uv run --frozen python scripts/check_stubs.py`).
Файлы не правишь, коммитов не делаешь.

### Чек-лист (по цене ошибки; каждое замечание — `файл:строка`)

1. **Секреты и данные.** Нет ключей, `.env`, данных организаторов, `cache/`, `indexes/`,
   файлов > 5 МБ; персональных данных физлиц сверх публичного в госреестрах.
2. **Утечка во времени в backtest.** Признаки или статистики контрагента считаются только
   по данным до `cutoff` (`configs/split.yaml`); тестовая закупка не входит в статистики
   своего поставщика; дубли склеены по ИНН до разбиения; holdout читается только через
   `src/eval/final.py` (`unseal()` больше нигде); `configs/split.yaml` не сдвинут под метрику.
3. **Факт без Evidence.** У каждого показанного факта есть `Evidence` с `url` и `fetched_at`;
   извлечённые ИНН/телефон/email/адрес проходят `src/enrich/evidence.py`
   (`check_counterparty` → пусто; есть тест); LLM извлекает, а не порождает; неразрешённая
   компания — `inn=None`, не угаданный ИНН.
4. **`# STUB` в демо-пути.** Новая заглушка помечена и пишет предупреждение в лог; после code
   freeze — блокирующее (`STUB_STRICT=1 make stubs`).
5. **Контракт.** Изменение `src/contracts.py` — только с перечнем потребителей в PR, обновлёнными
   `docs/openapi.json` и `src/ui/src/api-types.ts` (`make openapi-check`), после заморозки — с
   подтверждением человека. Молчаливая правка — «отклонить».
6. **Тест проверяет поведение.** На новую логику — тест через публичный интерфейс; тест,
   проходящий при любой реализации, не считается; ослабленные/отключённые тесты — блок.
7. **e2e демо.** Правка API, контракта или UI — `make e2e` не сломан, сценарий `docs/ui.md` не
   сокращён без записи в `research/DECISIONS.md`.
8. **Методология.** Изменение формулы скоринга или состава компонент — есть ли подтверждение
   человека (№3 в `CLAUDE.md`) и строка в DECISIONS; цифры в документах — из
   `eval/results/*.json`, с командой.
9. **Владение и объём.** Файлы в каталогах области задачи (`docs/project-structure.md`);
   diff в рамках критерия приёмки; `Closes #<N>`; зависимость — с записью в DECISIONS.
10. **Чистота.** Нет переформатирования соседнего кода, отладочного вывода, абстракций «на
    будущее». Идентификаторы английские, интерфейс и документы русские.

## Режим 2 — решение

Бриф: формулировка решения (трактовка условий, метод, контракт, стек), контекст — только
условия и diff/факты. Проверь: следует ли из условий и данных, есть ли дешевле альтернатива,
не противоречит ли `research/DECISIONS.md`, что сломается, если неверно. Вердикт:
**принять** (одна строка для DECISIONS) или **отклонить** (почему и что сделать вместо).
