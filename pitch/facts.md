## Производительность и масштаб

Полные данные организаторов (`data/processed`: 604 452 лота, 1 010 107 участий, 2 550 089 позиций, 44 196 поставщиков), 16 ядер.
Все замеры latency — серверное время `POST /api/search` внутри процесса (FastAPI `TestClient`, без сети), первая страница (20), 5 запросов
прогрева не считаются; dev-запросы несут ОКПД2 лота. **Условия всех замеров: кеш источников пуст, без сети (`DISCOVERY_OFFLINE=1`,
`ENRICH_OFFLINE=1`), один клиент без конкурентной нагрузки, одна машина разработчика** (16 ядер); блок «Новые» пуст (массовые запросы во
внешние источники — подтверждение человека №4). Живые источники не измерены. Условия каждого замера (load average, чужие процессы на
старте) — в блоке `conditions` самого json; разброс между повторными прогонами на тихой машине ±6% по p50. Память: поля `*_mb` в json —
КиБ/1024 из `/proc/<pid>/status`, то есть МиБ (не МБ); здесь — МиБ.
