## Принципы

- Демо идёт **на кеше, без интернета**: все ответы внешних источников лежат на диске; живые ФНС и ЕИС с сети площадки сейчас не отвечают
  (по сообщению команды 02.10, **[ПРОВЕРИТЬ на площадке до защиты]**), поэтому живого обогащения на защите нет и мы его не обещаем.

  чек-лист для любой из машин. Заведомо запасной путь — `make demo` на parquet (D-035).
- `# STUB` в демо-пути нет (`make stubs` после code freeze — ошибка); e2e зелёный (`make e2e`); полный `make check && make e2e` на свежем `main` — перед чек-поинтом и code freeze.

## Чек-лист «демо на кеше, без Wi-Fi»

За день до защиты / сразу после code freeze (на машине показа, с интернетом):

- [ ] Чистый `git clone` → `make setup` → данные (`make data PART=processed`, `docs/demo-clean-clone.md`) → `make demo` стартует с `status: ok`; **не** синтетическая фикстура (плашки «Демонстрационные данные» нет).
- [ ] Кеш источников: `cache/sources.sqlite` (и `cache/queue.sqlite`) на месте; копия каталога `cache/` лежит на второй машине и на флешке.
- [ ] Прогрев: `uv run python -m src.worker.prefetch --top 200` (внешнее, подтверждение №4), затем по каждой демо-закупке один поиск; блок «Новые» не пуст.
- [ ] У верхних 10 строк «С опытом» есть название и тип; у верхних строк «Новых» — роль с основанием и ссылкой на реестр.
- [ ] `uv run python scripts/own_lot_check.py <демо-лоты>` — результат записан; озвучка соответствует (см. F-13).
- [ ] `make stubs` — «в демо-пути нет # STUB»; `make e2e` зелёный; `make check` на свежем `main`.

За час до защиты:

- [ ] Wi-Fi **выключен**, `DISCOVERY_OFFLINE=1 ENRICH_OFFLINE=1`, сервис запущен заново **не позже чем за 10 минут до выступления** и прогрет (первый поиск после старта — до 84 секунд, не показывать залу).
- [ ] Полный сценарий (ниже) пройден без интернета от начала до выгрузки Excel; ни одной ссылки наружу не открыто (ссылки на реестры и внешние отзывы без сети не откроются — в показе по ним не кликаем).
- [ ] Браузер: полноэкранный, 1920×1080, масштаб 100%, закладка на `http://127.0.0.1:8000/`, уведомления ОС выключены, питание от сети, режим «уменьшить движение» включён.
- [ ] Выгруженный Excel и запасное видео лежат в известной всей команде папке (не только на машине показа); видео открывается без интернета.
- [ ] Вторая машина запущена в том же состоянии (запас), у кого она — `[решает команда]`.

В момент показа:

- [ ] Не обновлять страницу и не перезапускать API; если ответ не пришёл за 15 секунд — переход на запасное видео, а не ожидание.

| Запрос | Что произойдёт | Что говорим |

| Свободный текст с названием товара, без ОКПД2 | блок «С опытом» работает; блок «Новые» строится по классу ОКПД2, который подбор определил по тексту (D-141, `DISCOVERY_PREDICTED_CLASS`); ответы реестра МСП берутся из кеша — для класса, которого в кеше нет, при `DISCOVERY_OFFLINE=1` блок пуст | «Класс определён по тексту автоматически; при ошибке в классе блок «Новые» покажет другие компании — код можно задать загрузкой закупки по номеру» |
| Товар, по которому реестр МСП не прогрет в кеше | при `DISCOVERY_OFFLINE=1` «Новые» пусты | «Живой поиск мы на защите не включаем; в кеше этого класса нет» |
