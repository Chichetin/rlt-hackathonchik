# Страховка демо и запасное видео

Источник: разделы 10 и 12 («Страховка демо») `docs/source/hackathon-research-workflow.md`.
Проверяется скиллом `submission-checklist`.

## Страховка

- `make demo` поднимает всё одной командой с чистого клона и проверен **на той машине, с которой
  будет показ** (`[СПРОСИТЬ]` команда — какая машина).
- Демо-запросы и их результаты закешированы (`src/sources/cache.py`); демо не зависит от внешних
  API и Wi-Fi площадки.
- Запасное видео записано до code freeze (02.10, 16:30, `docs/timeline.md`).
- Никаких захардкоженных «красивых» ответов: жюри может попросить свой запрос.
- `# STUB` в демо-пути нет (`make stubs` после code freeze — ошибка).
- e2e демо-сценария зелёный (`make e2e`).

## Сценарий запасного видео (60–90 с)

Шаги — из `docs/ui.md` (тот же сценарий, что e2e `src/ui/e2e/demo.spec.ts`):

1. Ввести наименование товара или вставить позиции из ТЗ — реальная закупка СПб (демо-лот ЭМ из T-05).
2. Показать два блока: «С опытом госзакупок» и «Новые из открытых источников», score и
   объяснение в одну строку.
3. Открыть карточку: компоненты скоринга, факты с источниками и датами, контакты, тип
   (производитель/дистрибьютор), МСП, РНП.
4. Включить фильтр (только МСП / только производители / регион).
5. Выгрузить список в Excel.

Запись: разрешение 1920×1080, без звука или с короткой озвучкой; файл — `[СПРОСИТЬ Q-12]` куда
кладём (не в git, если > 5 МБ).

## Проверенный локальный сценарий — 01.10.2026

На машине с данными организаторов и прогретым API `http://localhost:8000/`:

1. Загрузить закупку **5903085 — «Поставка хозяйственных шкафов»**. Должны заполниться
   НМЦК **588 920 ₽** и ОКПД2 **31.01.11.120**. Нажать «Найти поставщиков».
2. Показать оба блока. При проверке получено **200** кандидатов из истории и **10** новых
   компаний (на первой странице истории — 20). Это размер выдачи конкретного запроса,
   **не метрика качества** и не гарантия числа результатов после обновления данных.
3. Открыть первого кандидата из истории: показать похожие закупки и компоненты оценки.
   Если название пока отсутствует, интерфейс показывает ИНН — не выдавать его за обогащённую компанию.
4. Открыть первую новую компанию: показать основание роли, реестр МСП и дату источника.
   Совпадение по ОКВЭД означает профиль деятельности; наличие конкретного товара требует проверки.
5. Включить «Только производители», пояснить скрытые записи с неизвестной ролью,
   затем выгрузить текущий список в Excel.

Запасные реальные закупки: **5875992** (оргтехника), **6050858** (марля).
При проверке обе дали по 200 кандидатов из истории и 10 новых компаний.

Перед показом один раз выполнить поиск: после запуска загрузка индексов на этой машине
занимала до 84 секунд. `/api/health` со `status: ok` сам по себе не означает, что поиск
уже прогрет. Не перезапускать API непосредственно перед выступлением.

Свежие снимки с указанием лота и состояния сервера в `capture.json`:

```bash
BASE=http://127.0.0.1:8000 SCREENSHOT_DIR=cache/defense node scripts/screenshots.mjs 5903085
```

`cache/defense/` исключён из git. Файлы из `pitch/screenshots/` всё ещё относятся к старой
синтетической фикстуре; для текущего показа брать свежие снимки из `cache/defense/`.
Видео и Excel нужно заранее скопировать с машины показа в доступное команде место.
