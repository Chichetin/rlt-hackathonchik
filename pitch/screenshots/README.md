# Скриншоты skeleton

Сняты `node scripts/screenshots.mjs` при поднятом `make demo` на **синтетической фикстуре**
(`tests/fixtures/ingest`, ИНН выдуманные) — это не результат на данных организаторов. Плашка
«Демонстрационные данные» на снимках видна. Для питча пересними на реальных данных
(`docs/demo-clean-clone.md`).
