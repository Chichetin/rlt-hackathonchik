Контекст: хакатон RLT.Hack (Росэлторг), 2 октября 2026, до feature freeze несколько часов (изменения — часы, не дни). Сервис подбирает поставщиков к лоту госзакупки Санкт-Петербурга (АИС ГЗ и Электронный магазин, 44-ФЗ ст. 93). Запрос — текст лота: короткие русские названия позиций (1–15 слов: «бумага для офисной техники А4», «перчатки нитриловые смотровые», «картридж HP CF259X», много аббревиатур, марок, ГОСТ). Поиск идёт по 1 031 361 уникальному нормализованному названию позиций из истории 2024–2025 (1 047 638 документов в индексе), затем найденные позиции агрегируются в поставщиков (ИНН) и скорятся формулой: product_fit 0.762 (= 0.8·BM25 + 0.2·глубина совпадения кода ОКПД2), experience 0.19 (лоты и победы поставщика среди похожих позиций), activity 0.048. Демо работает на CPU-ноутбуке (Intel Core Ultra, 16 ГБ RAM, без GPU), бюджет p95 ≈ 2 с на запрос; корпус можно перекодировать заранее на RTX 4080 16 ГБ.

Текущий стек ретривера: bm25s (Python, Lucene-вариант, k1=1.5, b=0.75 по умолчанию), токенизатор prefix5 (слово обрезается до 5 символов), BM25 top-500. Опционально «pg_hybrid»: + pgvector HNSW kNN top-1000 (ef_search=1000) по intfloat/multilingual-e5-small (384 dim, max_seq_length 128, префиксы «query: »/«passage: ») → Reciprocal Rank Fusion k=60. По умолчанию в продукте только BM25.

Наши замеры (temporal split, dev = лоты после 2025-07-01; метрики по реальным победителям лота; 95% bootstrap CI):
Ступень 1, 500 dev-запросов. cand_recall@200 — доля победителей среди 200 кандидатов-поставщиков; recall@10 — в топ-10 простого порядка ретривера.

- BM25 Snowball: 0.771 / 0.428; короткий 0.745 / 0.405. BM25 pymorphy3 (лемматизация): 0.768 / 0.436; короткий 0.742 / 0.408 (всё в пределах шума)
- Только вектор, полный текст: e5-small 0.600 / 0.301; rubert-tiny2 0.572 / 0.260; deepvk/USER-base 0.623 / 0.299 (на 0.15–0.20 хуже BM25)
- Только вектор, короткий запрос: e5-small 0.719 / 0.386; e5-base 0.722 / 0.376; rubert-tiny2 0.702 / 0.378; USER-base 0.739 / 0.404

Потолок кандидатов ≈ 0.77: ~23% победителей вообще не попадают в 200 кандидатов.
