# Государственные источники

- **ЕГРЮЛ/ЕГРИП (ФНС)** – официальный реестр ФНС (единый гос. реестр юрлиц и ИП) содержит название, ОГРН, ОКВЭД, адрес, статус и др., но общедоступный API ФНС отсутствует (еgrul.nalog.ru работает через CAPTCHA). В качестве альтернативы можно использовать опендату ФНС: существуют «офлайн‑выгрузки» реестра (напр. проект OpenSanctions публикует полный дамп EGRUL по данным ФНС). Прямого «государственного» API нет, поэтому на практике пользуются агрегаторами или скачивают официальные XML‑выгрузки (см. ниже). 

- **Реестр субъектов МСП (ФНС)** – единый реестр малых и средних предприятий (ИНН/ОГРН, категория (микро/малые/средние), средняя численность, дата включения в реестр) открыт через портал nalog.gov.ru (rmsp.nalog.ru) и опендата. Регулярно публикуются ZIP‑файлы XML с данными реестра (название сета 7707329152-rsmp). По 10 октября 2026 г. обновление ежемесячное (последнее – 10.09.2026). Доступен поиск по ИНН и экспорт в Excel через web-интерфейс. Этот реестр позволяет узнать, относится ли компания к МСП и с какого числа она в реестре. 

- **Государственный информационный ресурс о БО (ФНС)** – реестр бенефициарных владельцев (bo.nalog.ru) формально есть, но API или выгрузки не объявлены. 
  (Возможная гипотеза: данные доступны только через web-сервис ФНС.) *UNKNOWN*

- **РНП (ФАС/EIS)** – «реестр недобросовестных поставщиков» ведется в Единой информационной системе в сфере закупок (zakupki.gov.ru). На сайте ЕИС доступен поиск по 44‑ФЗ, но открытого API нет. Можно вручную искать ИНН в интерфейсе РНП (реестр ФАС по ст.104 44-ФЗ). *UNKNOWN*

- **Реестр контрактов ЕИС** – сведения о госконтрактах (ФКС) доступны через портал zakupki.gov.ru. Существуют FTP‑раздачи данных ЕИС (контракты, протоколы), но они сложны для оперативного использования. Для быстрого демо лучше обходиться агрегаторами контрактов (см. ClearSpending). *UNKNOWN*

- **ГИСП / Минпромторг** – существует портал «Государственная информационная система промышленной продукции» (ГИСП) и другие отраслевые реестры Минпромторга (реестр производителей, органической продукции и т.д.). Установленный API не найден. Возможно, данные можно запрашивать на сайте Минпромторга или через его подразделения, но на горизонте хакатона – **HYPOTHESIS**.

- **ЕФРСБ (Федресурс, банкротство)** – единый реестр сведений о банкротстве (bankrot.fedresurs.ru) – открытый портал, но без публичного API (только поиск по ФИО/ИНН на сайте). Дамп нет. Можно отметить, что сведения об участии компании в банкротстве доступны через FedResurs (поиск в реестре банкротов).

- **ФССП** – «Банк данных исполнительных производств» доступен на сайте fssp.gov.ru (поиск по ИНН/ФИО должника). API не заявлен. Можно скриптовать поиск, но это сложно и капчей не защищено (доступен интерфейс).

- **Росаккредитация** – реестры аккредитации (отраслевые стандарты, ИТ-компании и т.п.) есть на разных площадках (напр. сайт госуслуг, digital.gov.ru), но единый API нет. Возможно, данные можно грабить с веб-интерфейсов. *UNKNOWN*

- **Портал data.gov.ru** – общероссийский портал открытых данных содержит ссылки на многие наборы (например, реестры ФНС, Минпром и др.), но сами данные берутся с ведомственных сайтов. Полезен для навигации, но специфичных сведений по ИНН тут нет.

- **Портал госзаказа СПб** – региональный портал закупок Санкт-Петербурга (zakupki.gov.spb.ru). Есть данные по закупкам СПб, но API/выгрузка неизвестны. Вероятно, можно парсить интерфейс сайта. *HYPOTHESIS*

# Коммерческие агрегаторы (API и сервисы)

- **DaData** – облачный API очищения и обогащения данных (dadata.ru). Есть метод **«Организация по ИНН»**, который по ИНН/КПП/ОГРН возвращает реквизиты и массу сведений: наименование, статус (действующее/ликвидировано), юридический адрес, коды ОКВЭД, среднесписочная численность, уставный капитал, сведения о регистрациях (в т.ч. в МСП-реестре), спецрежиме, бухгалтерскую отчётность (доходы/расходы) и долговые данные, а также ФИО гендиректора и учредителей с долями. Разумеется, DaData не является «госслужбой», но берёт данные из государственных реестров (ЕГРЮЛ/ЕГРИП, ПФР/ФСС, МСП-реестр и др.). **Поля:** в ответе есть ИНН, КПП, ОГРН, ОКВЭД, адрес, статус, балансы, кадастровые, Лицензии, МСП, лицензии, банковские сведения и пр.. **Доступ:** REST‑API (JSON). **Лимиты:** есть бесплатный тариф – до 10 000 запросов в сутки; более быстрый доступ по платной подписке (50–200 тыс. в день за 14–56 тыс.₽/год). **Лицензия/условия:** нужна регистрация, коммерческое использование бесплатно до 10k/день; далее – по подписке. Актуальность данных – ежедневно обновляется (скрытая внутренняя частота, г-н DaData гарантирует свежесть гос. данных). **Пример запроса:** `GET https://suggestions.dadata.ru/suggestions/api/4_1/rs/findById/party` с параметром `"query":"<ИНН>"` (возвращает JSON со всеми полями). 

- **Checko** – коммерческий сервис проверки контрагентов (checko.ru). Предлагает API и готовые базы компаний (можно скачать партии данных, анализы рисков). Политика цен не опубликована открыто. Известно, что есть выгодный (бесплатный?) демо‑доступ, но полноценный API платный. *UNKNOWN*

- **ofdata.ru** – (официально сайт проекта «Общероссийский рейтинг организаций»?) Скорее всего, интернет‑справочник. Информации об API не найдено. Скорее всего, только веб-поиск.

- **ZACHESNYBIZNES.ru** – портал правительственной поддержки бизнеса. Позволяет искать компаний по ИНН/названию, показывает часть реестров (контракты, МСП, пр.), но API нет, доступ только веб. Без регистрации. *UNKNOWN (нет API)*

- **Rusprofile.ru, List-org.com** – популярные веб‑каталоги юридических лиц. Поиск по ИНН/названию, бесплатно выдаются основные реквизиты и история изменений. API у них нет (только платные партнерские договоры). Можно использовать как резерв (парсить HTML) или вручную. *HYPOTHESIS*

- **Контур.Фокус, СБИС, СПАРК (Интерфакс)** – крупные коммерческие системы по данным о контрагентах. У всех есть платный доступ/API, но нет бесплатного тарифа. На хакатоне их использовать нет времени и средств. Отметим, что **СБИС «реестры»** (sbis.ru) содержит похожую информацию (есть поиск по ИНН через личный кабинет, но защищен).

- **ClearSpending / ГосЗатраты** – публичные порталы мониторинга государственных контрактов (clearspending.ru = сайт Фонда «Честные закупки»). Открыты для чтения, есть собственный API для данных контрактов. Позволяют получить список контрактов и заказчиков по ИНН. Лимиты небольшие, но можно запросить реестр контрактов нужной компании. Доступ: REST (требуется токен) или открытые CSV/JSON-файлы по запросам. **Пример:** получить контракты по ИНН через метод API (см. документацию ClearSpending). *Дата проверки тарифов API:* неизвестно. (Примечание: иногда блокируется по частым запросам.)

- **GosZatraty.ru** – аналогичный портал (бывш. «Госзатраты»). Методы API открыты (есть документация на сайте). Позволяет искать финансирование по ИНН. Бесплатен. **Пример:** open API строка `goszatraty.ru/swagger`.

# Поиск новых поставщиков по товарам

Для подбора новых контрагентов по ассортименту можно использовать **каталоги и маркетплейсы B2B**. Например, **ГИСП** (каталог промышленной продукции) или отраслевые каталоги производителей позволяют искать компании по наименованию продукции. Также популярны B2B-рынки («Аллбиз», «Б2Б Маркет», торговые площадки, каталоги «Каталог.ру» и т.д.). Обычно такой поиск возвращает название компании и сайт. Далее можно сопоставить с ИНН через DaData или веб-поиск. Т.е. сначала находим название/контакты фирмы, затем уточняем ИНН через тот же DaData («Организация по ИНН») или через сайт ФНС. При этом стоит консолидировать информацию: если найдены сайт или контакты, можно также попытаться найти ИНН по названию (утилита DaData «suggestions/api/4_1/rs/suggest/party» помогает угадать ИНН по части названия). 

# Что подключить оперативно и запасной план

- **Легко подключить за часы:** 
  - *DaData API* – быстро регистрируетесь и сразу делаете запросы по ИНН (бесплатно до 10k/день). Возвращает большинство нужных полей (см. выше). 
  - *OpenData ФНС* – сразу качаете ZIP с данными реестра МСП (в нём ~2–3 млн записей, но выгрузка свежая). Распаковываете XML – получаете поля: ИНН, ОГРН, категории МСП, дату включения и т.д.
  - *ClearSpending/GosZatraty API* – нужен ключ, но получить можно; позволяет дозапросить информацию по известному ИНН о государственных контрактах (финансирование). Подключается за час при наличии регистрации.
  - *ZachestnyBusiness, Rusprofile* – быстренько пробиться парсерами через их API (по факту HTML) для уточнения отдельных полей (без ограничений, но капча возможна).

- **Запасной вариант при капче ФНС:** если сайт ФНС блокирует скрипты, используем исключительно **офлайн‑выгрузки**. Открытые наборы nalog.gov.ru/opendata (например, МСП) скачать сложнее, чем API, но они есть. Для ЕГРЮЛ можно брать дампы OpenSanctions или сторонних проектов, если официальный доступ закрыт. 

- **Кратко о надежности:** госданные ФНС в целом актуальны (отражают состояние на дату выгрузки). Агрегаторы обычно своевременны (DaData обновляет данные ежедневно). Коммерческие справочники («Фокус», SPARK) считаются очень надёжными, но их мы здесь не используем.
